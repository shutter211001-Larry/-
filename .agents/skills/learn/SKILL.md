# Learn

找出這次回饋中的原本目標、偏差、有效修正與證據。只保存已確認有效、可在相似任務重用、具體可檢查，而且不含敏感資料的規則。

全專案規則寫入 `AGENTS.md`；特定任務方法更新相應 Skill；本次才適用的資訊留在 Project brief。修改前檢查是否和既有規則衝突，修改後回報更新了哪條規則，以及下次如何驗證。
