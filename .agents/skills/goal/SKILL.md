# Goal

1. 用一句話重述最終成果。
2. 從對話與專案取得已知限制，不重複詢問已有答案。
3. 列出可驗證的完成條件與必要里程碑。
4. 先執行不依賴使用者決定的工作；只有缺少會改變方向的資訊時才提問。
5. 每次更新說明已完成、目前發現、下一步與阻礙。
6. 只有所有完成條件都滿足時才宣告完成。

不要把部分進度寫成完成，也不要把目標擴張到未授權的外部發布、付費或不可逆操作。
