# 🚀 AI 協作與生成實戰 (一日課程)

歡迎來到本專案！這是一份結合了 Agent 概念、GitHub 專案管理、閉環學習心法，以及 Comfy Cloud 實戰的完整教材。
我們強調「痛點導向」學習，在每個章節都會從真實的崩潰情境出發，讓您深刻體會「為什麼要學這個」。

---

## 📚 課程目錄與學習路徑

本教材強烈建議按照以下順序進行學習，這是一條由淺入深、從工具管理到雲端實戰的完美路徑：

1. **[01_Agent與SKILL基礎](./01_Agent與SKILL基礎.md)**
   > 認識你的數位專案經理 (PM)，打下與 AI 協作的核心觀念。
2. **[02_Antigravity與GitHub協作](./02_Antigravity與GitHub協作.md)**
   > 立刻將 AI 應用於專案管理，告別「最終版.psd」的惡夢。
3. **[03_學習指南與閉環機制](./03_學習指南與閉環機制.md)**
   > 掌握 Plan-Draft-Critique-Correct 四步循環，為專案打疫苗。
4. **[04_終極心法_用Agent設計Agent](./04_終極心法_用Agent設計Agent.md)**
   > 壓軸神技：不用手寫程式，讓 Agent 幫你建構完整的 SKILL 與工作流！
5. **[05_進階提示詞與ComfyCloud準備](./05_進階提示詞與ComfyCloud準備.md)**
   > 運用 CREATE 框架結構化您的需求，精準控制生成結果。
6. **[06_ComfyCloud實戰](./06_ComfyCloud實戰.md)**
   > 登入雲端美術外包中心，實作節點式工作流，將提示詞化為視覺藝術。
7. **[07_高階快捷指令與自動化](./07_高階快捷指令與自動化.md)**
   > 掌握 `/goal`、`/schedule` 等神級指令，讓 Agent 幫你自動加班！
