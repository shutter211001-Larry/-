Chapter 01 - 觀念一

本地與雲端大車拚

網頁 GPT 看不到你的世界
  • 受限的網頁工具 (Web GPT)：在網頁上用的 ChatGPT 看不到你電腦裡的檔案，遇到問題只能手動複製貼上、或手動上傳，就像是瞎子摸象。

Chapter 01 - 觀念二

為助理賦予靈魂與身分

賦予身分 (Persona)
  • 從維基百科到毒舌總監 (Persona 身分賦予)：AI 是一塊白紙。賦予身分後，他會主動挑剔你的構圖。這就是身分賦予帶來的行為轉變。
  • 統一的品牌規範 (SKILL 設定檔)：將專案的「主色調」寫入，未來產出永遠不會跑偏。不用每天碎碎念交接。
📄 SKILL.md 撰寫範例 (注意最上方的員工識別證)
---
name: "hair_makeup_director"
description: "專門負責審閱構圖與色彩學的美術總監" # 這是給 AI 看的觸發雷達，非常重要！
---
⬆️ 上面黃色這塊被 --- 包起來的區域，就是傳說中的 YAML Frontmatter (員工識別證)！
其中 description 是 AI 的「觸發雷達」，AI 會掃描這段來決定何時派這位專家出場。
🔴 失敗寫法：description: "昨天寫的測試技能" (AI 看不懂，永遠不會出場)
🟢 精準觸發：description: "專門審閱構圖與色彩學的美術總監" (AI 秒懂)
必須寫在檔案最頂端。下方則是真正影響說話語氣與行為的 Markdown 規則：

你是擁有 20 年經驗的資深美術總監。
當我給你草圖時，你必須嚴格針對「色彩學」與「視覺引導」給出三點具體的修改建議。說話風格必須犀利專業。

Chapter 02 - 觀念三

專案防護網 (.gitignore)

假裝沒看到的隱形斗篷
  • .gitignore 是一個純文字檔，裡面寫的任何檔名或路徑，Agent (與 Git) 都會假裝沒看到，絕對不會把它們上傳。這對於保護機密或過濾肥大設計檔非常重要！
📄 .gitignore 撰寫範例與萬用字元說明

* 代表「任何字元、任意長度」，就像大聲公喊「所有叫 OOO 的通通給我站出來」。

# 1. 利用萬用字元 (*) 忽略特定副檔名
# 只要檔案結尾是 .psd，不管前面叫什麼名字，全部忽略！
*.psd
*.psb
*.ai

# 2. 忽略特定資料夾內的所有東西
# 加上斜線代表「資料夾」。這會把 private 資料夾整包忽略。
/assets/private/

# 3. 忽略檔名包含特定關鍵字的檔案
# 只要檔名有 "secret" (例如 secret_passwords.doc) 都會忽略。
*secret*

# 4. 【例外條款】使用驚嘆號 (!) 建立白名單
# 忽略所有 .psd，但「唯獨這張」允許上傳備份！
!final_logo.psd

Chapter 03 - 觀念一

AI 記性很差

四步循環與無限重蹈覆轍
  • 無限初稿與審查 (Draft 與 Critique)：AI 犯錯沒關係，但如果你只是罵它「重畫」，它在下一個任務絕對會重犯一樣的錯誤。
  • 四步循環 (Plan ➔ Draft ➔ Critique ➔ Correct)：計畫 ➔ 初稿 ➔ 審查 ➔ 修正。大部分的人都卡在無限的 Draft 與 Critique，卻忘了把經驗 Correct 下來。

    名詞解釋：主模型與附屬擴充包

    Checkpoint

    主模型 (大腦與身體)

    LoRA

    外觀擴充包 (特效濾鏡)

    Low-Rank Adaptation。只要掛上一個幾百 MB 的檔案，就像給相機「裝上特殊濾鏡」，瞬間讓 AI 學會特定畫風或角色。

    Chapter 07 - 觀念補充

    什麼是模型精度 (FP16 / FP8)？

    FP16 (豪華原畫質)

    就像是相機的 RAW 檔。保留了最完美的色彩與光影細節，但檔案超級肥大，會吃掉很多顯卡記憶體。

    FP8 (輕量壓縮版)

    就像是高品質的 JPG 檔。檔案大小直接少一半，跑得更快，而且對設計師來說「肉眼幾乎看不出畫質差異」。

    那精度需要匹配嗎？

    完全不需要！ 精度只是「血袋的包裝大小」。只要血型 (架構) 正確，ComfyUI 醫院就會自動轉接處理。你可以放心將 FP8 壓縮版主模型配上 FP16 無損版 VAE 混搭使用！

    Chapter 07 - 關鍵技巧一

    下載時如何一眼辨識它是 Checkpoint 還是 LoRA？

    1. 看體重 (File Size)

    Checkpoint: 巨大，通常 6~12GB。
    LoRA: 輕量，通常只有 幾百 MB。

    2. 看格式與精度

    .safetensors: 最安全的格式。
    bf16 / fp8: 模型品質包裝（就像 RAW 或 JPG 檔）。

    3. 看標籤 (Type)

    Civitai 頁面會明確標示 Type: Checkpoint 或 Type: LoRA。

    Chapter 07 - 關鍵技巧二

    如何驗血？模型匹配三大招

    1. 看網站標籤

    在 Civitai 下載時，務必檢查右側的 Base Model 標籤 (例如 SDXL 或 FLUX.1 D)。這是最準確的血型證明。

    2. 看檔名暗示

    注意檔案名稱後綴。好心的作者通常會標示血型，例如 style_xl.safetensors 或 anime_flux.safetensors。

    3. 一條龍對齊

    如果你決定主機是 FLUX，那你的 VAE、LoRA、ControlNet 全都必須找 FLUX 版本。一個錯就全盤皆輸！
