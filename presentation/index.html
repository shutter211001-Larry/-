  • 受限的網頁工具 (Web GPT)：在網頁上用的 ChatGPT 看不到你電腦裡的檔案，遇到問題只能手動複製貼上、或手動上傳，就像是瞎子摸象。

Chapter 01 - 觀念二

為助理賦予靈魂與身分

賦予身分 (Persona)
  • 從維基百科到毒舌總監 (Persona 身分賦予)：AI 是一塊白紙。賦予身分後，他會主動挑剔你的構圖。這就是身分賦予帶來的行為轉變。
  • 統一的品牌規範 (SKILL 設定檔)：將專案的「主色調」寫入，未來產出永遠不會跑偏。不用每天碎碎念交接。
📄 SKILL.md 撰寫範例 (注意最上方的員工識別證)
---
name: "hair_makeup_director"
description: "專門負責審閱構圖與色彩學的美術總監" # 這是給 AI 看的觸發雷達，非常重要！
---
⬆️ 上面黃色這塊被 --- 包起來的區域，就是傳說中的 YAML Frontmatter (員工識別證)！
其中 description 是 AI 的「觸發雷達」，AI 會掃描這段來決定何時派這位專家出場。
🔴 失敗寫法：description: "昨天寫的測試技能" (AI 看不懂，永遠不會出場)
🟢 精準觸發：description: "專門審閱構圖與色彩學的美術總監" (AI 秒懂)
必須寫在檔案最頂端。下方則是真正影響說話語氣與行為的 Markdown 規則：

你是擁有 20 年經驗的資深美術總監。
當我提到銀河系挑染企劃時，你必須嚴格針對「材質細節」與「色彩搭配」給出三點具體的修改建議。說話風格必須犀利專業。

Chapter 02 - 觀念一

AI 記性很差

四步循環與無限重蹈覆轍
  • 無限初稿與審查 (Draft 與 Critique)：AI 犯錯沒關係，但如果你只是罵它「重畫」，它在下一個任務絕對會重犯一樣的錯誤。
  • 四步循環 (Plan ➔ Draft ➔ Critique ➔ Correct)：計畫 ➔ 初稿 ➔ 審查 ➔ 修正。大部分的人都卡在無限的 Draft 與 Critique，卻忘了把經驗 Correct 下來。

Chapter 02 - 觀念二

閉環機制：幫專案打一劑疫苗

AGENTS.md 規則庫
  • 建立免疫系統 (AGENTS.md 規則庫)：只要你進行 Critique 後，將「禁止六指」寫入專案的 AGENTS.md。下次 Agent 會讀到這條檢查規則，但成果仍要實際驗收。
  • 存放位置：專案專屬請放 .agents/ ；全域通用請放電腦家目錄 .gemini/config/ (Win 系統為 C:\Users\你的名字\.gemini\config\)。
  • 終極奧義 (全自動進化)：無須手動輸入！當你糾正完 Agent 後，直接輸入 「分析偏差並更新可重用規則」，或使用本專案的 /learn Skill；更新後要查看差異並說明下次如何驗證。
📄 幾個必懂的 AGENTS.md 撰寫規則
# 專案家規四大屬性 (AGENTS)

## 1. 🔄 學習指南 (Meta-Rule)
- **絕對遵守**：當解決完問題或被糾正錯誤後，必須「主動」檢討並更新相關 SKILL 或 AGENTS.md，確保不再犯錯。

## 2. 🎨 品牌規範 (Brand Rules)
- **視覺限制**：主打極簡保養品，主色調為大地色，嚴禁螢光色。
- **文案語氣**：化身為「帶有溫度的皮膚科醫生」，一律使用繁體中文。

## 3. 📋 工作流程 (Workflow Rules)
- **發文 SOP**：執行發文時，先調用 hair_makeup_director 審圖 ➔ 通過後調用 social_marketer 寫文案 ➔ 存入 output 資料夾。

## 4. 🚫 避坑清單 (Constraint Rules)
- **商業禁忌**：文案中絕對不能提到競品公司 (如 L'Oréal)。
- **物理限制**：生成人物時絕對禁止出現六根手指。

Chapter 02 - 觀念三

公司架構比喻：Agent vs SKILL

Agent (專案經理 PM)

Agent 就是中央大腦。它會自動讀取家規 (AGENTS.md)，並且認識你所有的員工 (SKILL)。

AGENTS.md (員工手冊)

  • 作用範圍：套用到全公司的所有任務。
  • 目的：定義底線與大方向 (如：禁止六指)。

SKILL (專業職位)

  • 作用範圍：針對特定的專業任務。
  • 目的：賦予特定身分 (如：毒舌總監)。

references/ (資料室)

  • 作用範圍：存放厚重設計規範。
  • 目的：釋放記憶空間，需要時翻閱。

    Chapter 06 - 觀念補充

    什麼是模型精度 (FP16 / FP8)？

    FP16 (豪華原畫質)

    就像是相機的 RAW 檔。保留了最完美的色彩與光影細節，但檔案超級肥大，會吃掉很多顯卡記憶體。

    FP8 (輕量壓縮版)

    就像是高品質的 JPG 檔。檔案大小直接少一半，跑得更快，而且對設計師來說「肉眼幾乎看不出畫質差異」。

    那精度需要匹配嗎？

    完全不需要！ 精度只是「血袋的包裝大小」。只要血型 (架構) 正確，ComfyUI 醫院就會自動轉接處理。你可以放心將 FP8 壓縮版主模型配上 FP16 無損版 VAE 混搭使用！

    下載時如何一眼辨識它是 Checkpoint 還是 LoRA？

    1. 看體重 (File Size)

    Checkpoint: 巨大，通常 6~12GB。
    LoRA: 輕量，通常只有 幾百 MB。

    2. 看格式與精度

    .safetensors: 最安全的格式。
    bf16 / fp8: 模型品質包裝（就像 RAW 或 JPG 檔）。

    3. 看標籤 (Type)

    Civitai 頁面會明確標示 Type: Checkpoint 或 Type: LoRA。

    如何驗血？模型匹配三大招

    1. 看網站標籤

    在 Civitai 下載時，務必檢查右側的 Base Model 標籤 (例如 SDXL 或 FLUX.1 D)。這是最準確的血型證明。

    2. 看檔名暗示

    注意檔案名稱後綴。好心的作者通常會標示血型，例如 style_xl.safetensors 或 anime_flux.safetensors。

    3. 一條龍對齊

    如果你決定主機是 FLUX，那你的 VAE、LoRA、ControlNet 全都必須找 FLUX 版本。一個錯就全盤皆輸！

    • 遵循需求：能否保留品牌語氣、格式和禁止事項？
    • 實際成本：在你的帳號、地區與方案下，速度、額度和費用是否可接受？

    模型名稱與排行榜會更新。固定 brief 和驗收標準，再用目前可選的模型做小測試。

    💻 Chapter 07 - 實作一

    測試不同模型的文案風格

    實作時間：10 分鐘

    Chapter 07 - 觀念二

    影片生成模型 (Video AI)

    先確認這次需要哪種能力
    • 起點：文字生影片、圖片生影片，或指定首尾幀？
    • 控制：是否需要參考主體、多鏡頭、運鏡或動作控制？
    • 交付：比例、長度、聲音和後製銜接有什麼要求？
    • 驗收：主體一致、動作、鏡頭、結尾、時間與成本是否符合任務？

    Chapter 07 - 觀念三

    讓 Agent 依官方指南整理 Kling 提示詞

    先查模式，再決定提示詞需要哪些欄位

    圖生影片通常先說清楚主體如何動，再補充背景動態、鏡頭、結尾與必須保留的內容。起始圖片已提供的資訊，不必全部重複。

    💻 Chapter 07 - 實作二

    為模特兒打造專屬情境短片 (圖生影)

    實作時間：10 分鐘

    • 打開 【Kling】分頁 ➔ 點擊 【Image to Video】 ➔ 上傳起始圖片。
    • 請 Agent 根據官方指南與起始圖整理提示詞："The model turns slowly while keeping her face and galaxy highlights consistent. The camera makes a gentle push-in and holds on the hairstyle." ➔ 點擊 【Generate】。
    ⚠️ 避坑 TIP (新手大坑)：千萬不要讓提示詞與原圖片產生嚴重的場景衝突，否則 AI 會為了強行改變背景，導致主角的臉與髮型變形崩壞！
    Chapter 07 - 觀念四

    首尾幀控制 (Start/End Frames)

    指定起迄點：給演員畫好走位圖

    如果「圖生影」只是給 AI 參考起點，那「首尾幀」就是給 AI 指定起迄點。你給演員一張「開場」的走位圖（首幀），再給一張「殺青」時的走位圖（尾幀），AI 會自動幫你把中間的動作補齊 (Interpolation)。

    💻 Chapter 07 - 實作三

    用首尾幀製作完美的髮色變化

    實作時間：5 分鐘

    • 開啟 【Start/End Frames】。
    • 首幀上傳「銀河系挑染」，尾幀上傳「龐克粉紅短髮」(需確保角度一致)。
    • 提示詞輸入："The model is transforming clothes smoothly" ➔ 點擊 【Generate】。
      介面名稱與位置可能更新。實作前先確認目前帳號是否提供首尾幀功能，再依當天畫面操作。
    ⚠️ 避坑 TIP (新手大坑)：首尾幀的圖片，光影和人物比例絕對不能差太多！否則 AI 會不知道怎麼補中間的空間過渡，導致人物在中途像異形一樣融化變異！
    🎉 檢查最終成果：對照首幀、尾幀、人物比例與髮色變化。若中途變形，一次只調整一個主要變因並記錄結果。
