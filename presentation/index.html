Chapter 01 - 觀念一

IDE Agent (數位工作室 / 頂級畫室) vs Web GPT

網頁 GPT 看不到你的世界
  • Web GPT (瞎子摸象)：在網頁上用的 ChatGPT 看不到你電腦裡的檔案，遇到問題只能手動複製貼上、或手動上傳。
  • IDE Agent (數位工作室 / 頂級畫室) (長了眼睛跟手)：像是 Antigravity，它能直接讀取你本地資料夾的 PSD 與草圖，甚至幫你建立檔案、跑腳本。它是活在你電腦裡的「本地實習生」。

Chapter 01 - 觀念二

SKILL：為助理賦予靈魂與身分

賦予身分 (Persona)
  • 從維基百科到毒舌總監：AI 是一塊白紙。賦予身分後，他會主動挑剔你的構圖。這就是身分賦予帶來的行為轉變。
  • SKILL (設定檔) = 品牌規範：將專案的「主色調」寫入 SKILL，未來產出永遠不會跑偏。不用每天碎碎念交接。
📄 SKILL.md 撰寫範例 (注意最上方的員工識別證)
---
name: "art_director"
description: "專門負責審閱構圖與色彩學的美術總監" # 這是給 AI 看的觸發雷達，非常重要！
---
⬆️ 上面黃色這塊被 --- 包起來的區域，就是傳說中的 YAML Frontmatter (員工識別證)！
其中 description 是 AI 的「觸發雷達」，AI 會掃描這段來決定何時派這位專家出場。
🔴 失敗寫法：description: "昨天寫的測試技能" (AI 看不懂，永遠不會出場)
🟢 精準觸發：description: "專門審閱構圖與色彩學的美術總監" (AI 秒懂)
必須寫在檔案最頂端。下方則是真正影響說話語氣與行為的 Markdown 規則：

你是擁有 20 年經驗的資深美術總監。
當我給你草圖時，你必須嚴格針對「色彩學」與「視覺引導」給出三點具體的修改建議。說話風格必須犀利專業。

Chapter 02 - 觀念三

專案防護網 (.gitignore)

假裝沒看到的隱形斗篷
  • .gitignore 是一個純文字檔，裡面寫的任何檔名或路徑，Agent (與 Git) 都會假裝沒看到，絕對不會把它們上傳。這對於保護機密或過濾肥大設計檔非常重要！
📄 .gitignore 撰寫範例與萬用字元說明

* 代表「任何字元、任意長度」，就像大聲公喊「所有叫 OOO 的通通給我站出來」。

# 1. 利用萬用字元 (*) 忽略特定副檔名
# 只要檔案結尾是 .psd，不管前面叫什麼名字，全部忽略！
*.psd
*.psb
*.ai

# 2. 忽略特定資料夾內的所有東西
# 加上斜線代表「資料夾」。這會把 private 資料夾整包忽略。
/assets/private/

# 3. 忽略檔名包含特定關鍵字的檔案
# 只要檔名有 "secret" (例如 secret_passwords.doc) 都會忽略。
*secret*

# 4. 【例外條款】使用驚嘆號 (!) 建立白名單
# 忽略所有 .psd，但「唯獨這張」允許上傳備份！
!final_logo.psd

Chapter 03 - 觀念一

四步循環與無限重蹈覆轍

痛點解析
  • AI 記性很差：AI 犯錯沒關係，但如果你只是罵它「重畫」，它在下一個任務絕對會重犯一樣的錯誤。
  • 四步循環：Plan (計畫) ➔ Draft (初稿) ➔ Critique (審查) ➔ Correct (修正)。大部分的人都卡在無限的 Draft 與 Critique，卻忘了把經驗 Correct 下來。
💻 Chapter 03 - 實作一

死性不改的 AI

實作時間：15 分鐘

AI 雖然聰明，但沒有「長期記憶」，如果不把教訓固定下來，每次開新專案都要重新罵一次。這就需要下一個觀念！
Chapter 03 - 觀念二

閉環機制：幫專案打一劑疫苗

AGENTS.md 規則庫
  • 免疫系統建立：只要你進行 Critique 後，將「禁止六指」寫入專案的 AGENTS.md。整個專案就像打了疫苗一樣，永遠對六指免疫。這就是知識沉澱的威力。
  • 存放位置：專案專屬請放 .agents/ ；全域通用請放電腦家目錄 .gemini/config/ (Win 系統為 C:\Users\你的名字\.gemini\config\)。
  • 終極奧義 (全自動進化)：無須手動輸入！當你糾正完 Agent 後，直接輸入 「把教訓寫入 AGENTS.md」，或是打上神級指令 /learn，Agent 就會自己把規則庫更新好！這才是閉環的魔法。
📄 .agents/AGENTS.md 撰寫範例
# 專案家規四大屬性 (AGENTS)

## 1. 🔄 自動閉環機制 (Meta-Rule)
- **絕對遵守**：當解決完問題或被糾正錯誤後，必須「主動」檢討並更新相關 SKILL 或 AGENTS.md，確保不再犯錯。

## 2. 🎨 品牌與風格規範 (Brand Rules)
- **視覺限制**：主打極簡保養品，主色調為大地色，嚴禁螢光色。
- **文案語氣**：化身為「帶有溫度的皮膚科醫生」，一律使用繁體中文。

## 3. 📋 工作流規範 (Workflow Rules)
- **發文 SOP**：執行發文時，先調用 art_director 審圖 ➔ 通過後調用 social_marketer 寫文案 ➔ 存入 output 資料夾。

## 4. 🚫 避坑與限制清單 (Constraint Rules)
- **商業禁忌**：文案中絕對不能提到競品公司 (如 L'Oréal)。
- **物理限制**：生成人物時絕對禁止出現六根手指。

公司架構比喻：Agent vs SKILL

AGENTS.md (員工手冊)

  • 作用範圍：套用到全公司的所有任務。
  • 目的：定義底線與大方向 (如：禁止六指)。

SKILL (專業職位)

  • 作用範圍：針對特定的專業任務。
  • 目的：賦予特定身分 (如：毒舌總監)。

references/ (資料室)

  • 作用範圍：存放厚重設計規範。
  • 目的：釋放記憶空間，需要時翻閱。
Agent (專案經理 PM)

    Chapter 07 - 觀念補充

    什麼是模型精度 (FP16 / FP8)？

    FP16 (豪華原畫質)

    就像是相機的 RAW 檔。保留了最完美的色彩與光影細節，但檔案超級肥大，會吃掉很多顯卡記憶體。

    FP8 (輕量壓縮版)

    就像是高品質的 JPG 檔。檔案大小直接少一半，跑得更快，而且對設計師來說「肉眼幾乎看不出畫質差異」。

    那精度需要匹配嗎？

    完全不需要！ 精度只是「血袋的包裝大小」。只要血型 (架構) 正確，ComfyUI 醫院就會自動轉接處理。你可以放心將 FP8 壓縮版主模型配上 FP16 無損版 VAE 混搭使用！

    Chapter 07 - 關鍵技巧

    如何驗血？模型匹配三大招

    1. 看網站標籤

    在 Civitai 下載時，務必檢查右側的 Base Model 標籤 (例如 SDXL 或 FLUX.1 D)。這是最準確的血型證明。

    2. 看檔名暗示

    注意檔案名稱後綴。好心的作者通常會標示血型，例如 style_xl.safetensors 或 anime_flux.safetensors。

    3. 一條龍對齊

    如果你決定主機是 FLUX，那你的 VAE、LoRA、ControlNet 全都必須找 FLUX 版本。一個錯就全盤皆輸！

    • 下載前看血型： Civitai 下載任何模型時，務必確認它標示為 SD1.5, SDXL 或 FLUX。
    • VAE 也是共犯： 很多時候 Checkpoint 沒錯，是 VAE 拿錯洗劑。SDXL 必配 SDXL VAE！
