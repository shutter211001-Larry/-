# 商品短片練習專案規則

## 任務說明

- 用途：9:16 社群短片
- 主體：舒緩控油髮露
- 訴求：清爽控油、柑橘與茉莉的感官意象
- 必須保留：瓶身比例、標籤內容、產品辨識度
- 素材：由講師提供的首幀與商品參考圖

## 工作規則

1. 先列出讀取的專案素材和官方來源，再提出提示詞。
2. 分清專案規則、這次任務說明與模型官方建議。
3. 缺少會影響模式或內容的資訊時先詢問；其他假設要明確標示。
4. 生成前先交付需求摘要、方法判讀、提示詞草稿與小測試方式。
5. 生成後檢查商品保真、主要動作、鏡頭和結尾；一次只調整一個主要變因。
6. 功能、模型名稱、長度與額度以執行當天的 Kling MCP 回傳內容為準。
