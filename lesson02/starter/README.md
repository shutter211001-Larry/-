# 第二堂課堂練習專案

把這個資料夾複製成自己的練習專案，然後用高階中文指令交辦：

> 請先讀 `.agents/rules/AGENTS.md` 與素材說明，再查 Kling 官方的圖片生成影片指南，並用 `who_am_i`（帳號與能力查詢工具）取得目前 MCP 能力。列出來源、適用理由與限制，拆解需求後交付摘要、提示詞草稿、MCP 工具計畫與驗收方式；任何會扣點的生成先等我確認。確認後用 `file_upload`（檔案上傳工具）、`image_to_video`（圖片生成影片工具）、`query_tasks`（任務查詢工具）執行，保存生成任務編號，完成後依驗收標準檢查並記錄修改。

- `.agents/rules/AGENTS.md`：這個專案每次都要遵守的規則。
- `.agents/skills/kling-video-workflow/SKILL.md`：製作 Kling 影片時才載入的流程。

先改 `AGENTS.md` 裡的任務說明，再要求 Agent 執行。完成後，把已驗證且能重用的教訓寫回規則或 Skill。
