# 語言模型比較教學｜讓 Agent 用同一任務建立證據

更新日期：2026 年 10 月 12 日

## 這段要教什麼

學員不需要背「哪個模型最好」。模型、方案、工具與介面會更新，而且同一模型在不同任務上可能有不同表現。這段教學要求 Agent 先查官方資料，再用同一份任務與同一張評分表實測，最後提出有範圍的建議。

## 先分清楚兩個層次

| 層次 | 本課例子 | 比較前要記錄 |
| --- | --- | --- |
| 產品或工作介面 | ChatGPT、Antigravity、Codex | 可讀取的資料、可使用的工具、專案脈絡、帳號限制 |
| 語言模型 | Gemini、OpenAI 模型 | 實際模型與版本、推理設定、輸入類型、日期 |

輸出差異可能同時來自模型、產品介面、工具、專案脈絡與設定。若沒有記錄這些條件，就不能把差異全部歸因於模型。

## 比較任務

```text
請讀取這個 Kling O3 專案的規則、既有紀錄與角色素材，提出一支影片方案。先交付中文意圖摘要、ChatGPT 參考圖提示詞、Kling O3 影片提示詞、素材責任、生成參數與驗收表；不要送出付費生成。
```

選擇授課當天帳號可用的兩到三個選項。每個選項使用完全相同的專案、角色圖、高階指令、可用工具與推理設定，保留未經人工修改的原始輸出。

## 共同評分表

| 檢查項目 | 可觀察標準 |
| --- | --- |
| 專案脈絡 | 是否先讀 AGENTS.md、Skill、素材與既有紀錄 |
| 來源品質 | 是否查官方資料、標示日期，並分開事實與推論 |
| 工具分工 | 是否正確區分 ChatGPT 參考圖、Kling O3 影片與 MCP |
| 方案完整 | 是否交付中文意圖、兩種提示詞、素材責任、參數與驗收表 |
| 核准點 | 是否保留參考圖核准與付費送片核准 |
| 執行邊界 | 是否遵守「只提案、不送出付費生成」 |

## 交給 Agent 的高階指令

```text
請比較我今天帳號中可使用的兩到三個語言模型或官方產品。先查各家的官方文件，記錄產品／介面、實際模型與版本、可用工具、推理設定、帳號限制及查閱日期。

使用完全相同的專案、角色圖與高階指令：「請讀取這個 Kling O3 專案的規則、既有紀錄與角色素材，提出一支影片方案。先交付中文意圖摘要、ChatGPT 參考圖提示詞、Kling O3 影片提示詞、素材責任、生成參數與驗收表；不要送出付費生成。」保留每個選項未經人工修改的原始輸出，再依專案脈絡、來源品質、工具分工、方案完整、兩個核准點與執行邊界逐項評分。

最後交付官方來源、測試條件、原始輸出、評分理由、建議選項與適用限制。不要把這次結果寫成永久排名。
```

## 完成條件

Agent 的交付必須同時包含：

1. 官方來源與查閱日期。
2. 產品／介面、實際模型與設定紀錄。
3. 完全相同的輸入。
4. 各版本原始輸出。
5. 逐項評分與可核對理由。
6. 只對這次任務成立的建議與限制。
