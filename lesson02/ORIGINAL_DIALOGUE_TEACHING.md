來源：[`sources/Kling_O3_對話紀錄_2026-10-11.txt`](./sources/Kling_O3_對話紀錄_2026-10-11.txt)  
整理日期：2026 年 10 月 11 日

## 這份對話怎麼讀

這份紀錄不是用來背提示詞。課堂要追蹤的是：導演用高階語言做了哪些決定、Agent 補了哪些可檢查方案、哪個動作需要核准、錯誤如何被修成後續規則，以及執行後留下哪些證據。

原始 TXT 只含使用者可見對話、主要提示詞、核准點與生成結果，不含系統指令、內部推理、憑據或重複輪詢紀錄。

## 九個關鍵回合

| 回合 | 導演原話／事件 | Agent 的工作 | 教學判讀 |
| --- | --- | --- | --- |
| 1. 設定合作方式與模型 | 「我要建立一個新的工作流，由你產生提示詞並且調用 Kling MCP 幫我生成影片、還有提供給 O3 的參考圖像，我擔任導演。使用模型是 Kling O3。」 | 建立導演、Agent、ChatGPT Image Generation、Kling O3 與 MCP 的初始分工。 | 高階指令先定義目的、角色、工具與目標模型。 |
| 2. 導演提供提示詞範本 | 「這是提示詞範本，我們往後的提示詞風格都要照這個樣子。」接著貼上從 Comfy 工作流帶來的完整英文提示詞。 | 分析範本中的景別與主體、動作與環境、物理動態、焦點與模糊、色彩、光線與情緒順序。 | 提示詞風格不是 Agent 憑空發明；導演先提供基準，Agent 再拆解、轉譯並整理成工作方法。 |
| 3. 提出第一鏡 | 「我想要這個角色風格，讓他蹲下抬頭，鏡頭使用廣角鏡頭看他。」 | 把角色、蹲姿、抬頭和廣角補成低機位、20mm 感、夜間石造街景、焦點、光線、次要動態與兩份模型提示詞。 | 導演決定創意方向；Agent 補成可見、可修改、可核准的方案。 |
| 4. 第一次核准 | 「核准。」 | 依當時流程製作參考圖；但誤用 Kling Image O3。 | 核准是針對已提出的具體方案。若工具責任沒有寫清楚，核准後仍可能執行錯誤。 |
| 5. 糾正工作分工 | 「交代下去，圖片是由 CHAT GPT 生成。」 | 將正式參考圖改為 ChatGPT Image Generation；Kling 只負責影片。歷史 Kling 圖和 generationId 保留，但不再作正式輸入。 | 糾正不能只修眼前成品，也要更新後續規則、標出舊版本狀態並避免重複花費。 |
| 6. 正式參考圖與送片摘要 | ChatGPT 正式參考圖完成。 | 再次列出原始角色圖、ChatGPT 定稿圖、O3 提示詞、5 秒、16:9、1080p、1 版、多鏡頭關閉、同步音訊開啟，並聲明尚未核准前不扣點。 | 付費前要把素材責任、參數與執行邊界變成可檢查摘要。 |
| 7. 第二次核准 | 「生成第一段影片。」 | 只提交一次，保存正式影片的 generationId、taskTraceId 與 60 點歷史紀錄。 | 短指令可以成立，是因為前面已有完整可檢查摘要和明確執行邊界。 |
| 8. 追蹤與交付 | `QUEUING → RUNNING → COMPLETED` | 只查詢同一個 generationId，保存點數、完成時間、影片、封面與網址失效提醒。 | 工具顯示完成只證明任務完成；作品仍需用驗收表判斷。任務編號和本機檔案讓結果可追溯。 |
| 9. 保存對話 | 「你可以把我們的對話變成 TXT 檔給我嗎？」 | 把使用者可見對話、主要提示詞、核准點與生成結果整理成 UTF-8 TXT。 | 工作流需要留下可重讀、可教學、可追溯的紀錄。 |

## 對話中形成的工作流

1. 導演先設定合作方式、目標模型，並提供從 Comfy 帶來的提示詞描述基準。
2. Agent 分析範本結構，再讀取專案規則、既有素材、官方能力與舊結果。
3. Agent 交付中文意圖、參考圖方案、影片提示詞、素材責任、參數與驗收表。
4. 導演先核准參考圖方向。
5. 付費影片提交前，Agent 再提供完整送片摘要。
6. 導演以明確指令核准一次提交。
7. Agent 保存任務編號，只追蹤同一任務。
8. 完成後依驗收表檢查；修正版一次只改一個主要變因。
9. 本次素材與結果存入 Project；跨任務可重用的規則經驗證後才存入 Skill。

## 三層語言對照

| 層次 | 對話中的例子 | 保存位置 |
| --- | --- | --- |
| 導演給 Agent 的高階指令 | 「讓他蹲下抬頭，鏡頭使用廣角鏡頭看他。」 | 本次對話與鏡頭紀錄 |
| 專案給 Agent 的可重用規則 | 正式參考圖由 ChatGPT 產生；付費提交前先提供摘要；等待期間不重複提交。 | `AGENTS.md`、工作流或 Skill |
| Agent 給生成模型的輸入 | ChatGPT 參考圖提示詞、Kling O3 影片提示詞、圖片責任與生成參數。 | 本次 Project／SHOT 紀錄 |

## 課堂提問

1. 哪些決定明確來自導演？
2. 哪些細節是 Agent 提案，仍需要導演核准？
3. 第一次「核准」後為什麼仍然發生工具分工錯誤？
4. 哪一句話把單次修正變成後續規則？
5. 第二次核准前，Agent 提供了哪些可檢查資訊？
6. `COMPLETED` 能證明什麼？還不能證明什麼？

## 使用限制

- `kling-video-v3_0_omni`、點數、參數與介面能力是 2026 年 10 月 11 日的執行紀錄，不視為永久規格。
- 雲端成品網址可能失效，課堂應使用已保存的本機影片。
- 這次成功只證明該次流程可以完成，不證明相同提示詞適用所有人物、商品或模型。
