第二章｜選擇合適的工作模式 2／2

看任務需要什麼，不看產品名稱

用一般網頁對話

  • 問題可以一次回答
  • 不需要讀取整個專案
  • 不需要操作外部工具
  • 結果由人自行執行與保存

用 Agent

  • 任務需要多步驟持續推進
  • 必須讀檔、查來源與保持脈絡
  • 要修改檔案或操作 MCP
  • 需要核准點、驗收與可重跑紀錄
ChatGPT 接上專案資料、規則與工具時，也可以用 Agent 模式工作。差別在於能不能持續完成任務並留下證據。
判斷題：如果關掉對話後，還有人必須手動把回答搬到其他地方、逐項執行並自己記錄進度，這個任務通常還沒有被 Agent 化。

第二章｜分清楚影片模型

官方建議的輸入結構不同，Agent 要依目標模型重組

Kling VIDEO 3.0／Omni官方公式是主體、動作、場景，再選擇攝影語言、光線與氣氛；圖片生成影片時，圖片負責已看得見的外觀，文字描述要發生的動作。主體＋動作＋場景官方提示指南

Runway Gen-4.5官方圖片生成影片指南指出：輸入圖已決定主體、構圖、光線與風格，文字應集中描述動作、攝影機與時間進程。主體＋環境＋攝影機動作官方提示指南
Seedance 2.5官方產品說明展示依時間區段指定敘事、鏡位、動作與節奏，也支援多模態參考與時間點編輯；這不是完整提示詞規範。時間區段＋鏡頭事件＋參考責任官方產品說明
Wan 2.2／ComfyUIWan 官方程式庫提供提示詞擴寫、負面提示與取樣參數；ComfyUI 節點分工則是本課使用的工作流控制層。提示詞＋負面提示＋工作流參數官方程式庫＋專案策略
教學推論：固定創意意圖、素材與驗收標準，再依上述官方輸入責任改寫。這是公平測試的設計，不是「某種句型必然更好」的保證。

這條工作流是在對話中長出來的
